# UNION commands

499 commands, each pressed on UNION 1.0.0-beta.2, each with its exact step line, UNION's answer (green, or red in its own words naming what it needs first) and its options, one file per tab. An AI presses a command with `steps_run` (the step line) or `commands_run` (its name), and reads the whole registry with `commands_list`.
